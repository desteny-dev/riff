# Riff – Gitarre nach Gefühl

**App öffnen:** https://desteny-dev.github.io/riff/

Gitarre lernen ohne Noten: hören, nachmachen, mit Band spielen. Die App hört über das Mikrofon zu, erkennt Takt, Töne und Akkorde und zeigt jeden Griff an einer 3D-Gitarre – so, wie du deine Gitarre beim Runterschauen siehst.

- 11 Schritte: Groove → Rock-Motor → erster Riff → Power-Akkord → Em → C → G/D → **dein erster Song** → Auf und ab → Lagerfeuer-Rhythmus → freies Jammen
- Stimmgerät eingebaut · Tempo passt sich an · „Hör dich – mit Band" nach jedem Durchgang
- Läuft komplett im Browser, keine Anmeldung, Fortschritt bleibt auf dem Gerät
- Am Handy: „Zum Home-Bildschirm" → wie eine App, auch offline

Dieses Repository enthält die fertig gebaute Seite (`index.html`, eine Datei). Der Quellcode mit Tests liegt im Projektordner von Desteny Development.
